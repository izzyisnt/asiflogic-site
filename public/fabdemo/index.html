A part here is not a drawing with hopes attached — it is an intent: every requirement an object carrying its value, the design story that put it there, and the provenance of the number. Screening it against a vendor gives three honest answers, because vendors have three: MET, UNMET, and UNREAD — nobody has read the page yet, which is a research task, not a verdict. 8 · Geometry out, order in

The blank ring above the downloads — OD 76 / ID 72 / h 16 mm — is emitted from the same fabfit constants the seam proofs check, so the file cannot disagree with the evidence. Through the measured 4.000 in bore it keeps 12.8 mm a side. Price bands are [I] on the ring’s 7.4 cm³: MJF ~$5, SLM ~$75. [I] band only — JLC3DP prices on the uploaded model's volume, bounding box, material and finish.

the order procedure1. Settle geometry against the constraints that already exist — for anything
living inside a globe, that includes the 4.000 in (101.6 mm) mount ID
([M operator, corrected 2026-08-02]; boards/orb_disc.py).
2. Pick a process with `select_process`; read the rejection reasons for the
ones it drops, they are usually informative.
3. Export STEP if the part came from real CAD, STL if it came from
`emit_stl_disc`. STL loses units — confirm mm on upload.
4. Upload at jlc3dp.com for an instant quote. The quote is the price; anything
this module said was a band.
5. Their DFM report flags thin walls and trapped volumes. Read it: it is a
second opinion from someone who owns the machine.
6. Order alongside a PCB run to share shipping — same account as JLCPCB.
